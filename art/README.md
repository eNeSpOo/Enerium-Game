# Арт

Исходники в полном размере. Происхождение и промпты генерации — в `provenance/`.

| Папка | Что |
|---|---|
| `heroes/` | Портреты пяти героев-заглушек (`hero-portrait-1…5.png`) |
| `enemies/workshop/` | Враги Мастерской форм с прозрачным фоном, из записей сказителя (таблица ниже) |
| `biomes/workshop/` | Зал Мастерской форм: четыре иллюстрации из того же PDF |
| `shelter/` | Убежище: комната, слой мебели (наковальня, стол) и четыре проводника — Энцо, Кузнец, Алхимик, Хранитель знаний (`shelter-mage.png`) |
| `items/` | Шесть ресурсов: Пепельное сердце, Полая корона, Пепельная печать, Могильный цвет, Грозовое стекло, Безмолвный колокол |
| `rewards/` | Сундук, кристаллы, золото, души, дух — крупные иллюстрации наград |
| `currency/` | Значки валют: золото, дух, души, Энериум, рунический ключ |
| `ui/` | Рамка, каменные панели, замок, значки статусов |
| `icons/paths/` | 41 иконка путей Странника — авторский набор |
| `characters/` | Странник (`wanderer.png`) |
| `reference/` | Референсы интерфейса и палитр из прошлой работы |
| `misc/` | Старые пробы: пещера, зверь, перчатки. Не утверждены |
| `style/` | Семь референсов стиля от автора (26.09.2026, без изменений) и `style.md` — палитра, свет, кадр, запреты, эталоны |
| `generated/` | Генерация через Gemini API скриптом `tools/art-gen/`. Черновики до одобрения автора (раздел ниже) |

## Сгенерированное

Каждая картинка записана в `generated/manifest.json`: файл, категория, промт, референсы стиля, модель, дата, параметры, токены, цена, проверка альфы. Смотреть — `generated/gallery.html`.

| Дата | Что | Модели | Статус |
|---|---|---|---|
| 26.09.2026 | Шесть референсов до пилота: ресурс «Тёплый замес», арена Мастерской форм сверху, портрет Ильмерры, иконка доблести, бафф «Оберег», способность «Остановка». Каждый — на трёх моделях для выбора | `gemini-3-pro-image`, `gemini-3.1-flash-image`, `gemini-3.1-flash-lite-image` | Приняты автором как основа стиля (ADR-0009). Эталоны — варианты Nano Banana 2, список в `style/style.md` |

Прозрачные иконки (`generated/icons/`, `generated/effects/`) сгенерированы на пурпурном ключе и вырезаны скриптом. Исходник лежит рядом как `….raw.jpg`.

## Внешние источники сырья

Берутся по задаче и только как арт; правила оттуда не переносятся.

**Старый Unity-проект** (архив, папка `Enerium-archive/EneriumFenix2`). В нём:
- спрайты Убежища, биомов и регистрации — около 520;
- текстуры частиц — 210;
- спрайты интерфейса — 143;
- гербы доблести, атлас редкостей, печати навыков и ульты.

Переносить вместе с `.meta` при создании нового клиента (ROADMAP, направление 7), иначе порвутся ссылки сцен.

**Библиотека второй версии игры, 2022 год** (`eNeSpOo/Enerium_New`, папка `Enerium_New`). Unity-проект, кода почти нет. В нём:
- около 6 000 иконок предметов по ремёслам: охота, кузнечество, зачарование, алхимия, инженерия, портняжное дело, ювелирное дело, кулинария, броня и оружие;
- около 2 400 иконок навыков, с фоном и без;
- герои, монстры, интерфейс с исходниками PSD, фоны;
- 44 префаба частиц с текстурами, 83 звука.

Шесть специализаций ресурсов из GDD (§9.2) совпадают с папками ремёсел.

**Лицензии.** В библиотеке 2022 года остались следы папок `REXARD` и `PONETI`: это издатели наборов иконок в Unity Asset Store. Лицензия Asset Store принадлежит покупателю. Прежде чем выпускать игру с этими иконками, проверить, на чей аккаунт куплены наборы. Если на аккаунт бывшего коллеги — нужна своя лицензия.
