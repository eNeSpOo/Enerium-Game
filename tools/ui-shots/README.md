# Кадры прототипа без окна браузера

`shots.js` снимает устройство прототипа безголовым Chrome по протоколу DevTools. Нужен, когда панель браузера в приложении скрыта — ночью, пока автор спит, её снимки устаревают. Ещё он ловит то, чего не видят проверки-расчёты: обрезанный текст, наезды, бледные числа.

```bash
node tools/ui-shots/shots.js tools/ui-shots/sample.json "$TMP/enerium-shots"
```

- Прототип должен отвечать на `http://localhost:8765/` — сервер превью `ui-prototype`.
- Кадр — PNG устройства (`.p-device`), вдвое крупнее CSS-пикселей. Смотреть — Read.
- В spec у кадра: `name`, `dev` (`932` или `844`), `js` — код, который ставит состояние и зовёт `render()`, `wait` — мс до снимка.
- Профиль Chrome — временный, во временной папке системы; профиль автора не трогается. Папку кадров держите вне репозитория или удаляйте.

Урок 30.09.2026: так нашёлся общий дефект — флаги «арт загружен» у `<html>` совпали с классами элементов, и весь прототип наследовал запрет переноса и заглавные буквы. Страж — в `check_heroes.js`.
