# Прототип интерфейса «Свет снизу»

Кликабельный прототип игры на экране телефона: 15 экранов вместо 94 прежних и 10 шаблонов окон поверх. Открыть — двойным щелчком по `index.html`, файл `battle.js` должен лежать рядом. Вкладки: «Прототип», «Карта экранов» (куда ушёл каждый старый экран), «UI-кит» (компоненты и цвета).

- **Статус:** направление одобрено автором 26.09.2026. Это ориентир для клиента Unity, а не код игры: клиент собирается объектами на сцене (ADR-0002).
- **Данные:** числа — демонстрационные заглушки. Реплики проводников, загадки ресурсов и главы — заглушки, не канон. Тексты врагов — из записей сказителя.
- **Концепция:** главное подсвечено снизу, как карст в трещинах Мастерской. Стихии окрашены в цвета карстов, таймеры показаны песком, неизученный враг — силуэтом.
- **Закрытая страница:** https://claude.ai/artifact/RSGkem7SAEWbXTmzr4NsKh. Версия с боем пять на пять туда ещё не выложена.

## Тестовая сцена боя пять на пять

Сценарий «Забег по Мастерской форм» в боковой панели. Бой собран по ADR-0004 и ADR-0005:
- пять карт героев против колоды этажа от одного до пяти врагов-карт;
- 35 этажей, у элит и босса есть свита, здоровье между этажами восстанавливается;
- попыток и энергии нет: сид этажа постоянен, повтор тем же отрядом даёт тот же итог;
- босс берётся осадой: урон по нему копится между забегами.

На карте бойца:
- полоса здоровья со щитом;
- золотая шкала — накопление атак до способности, бирюзовая — зарядка ульты;
- значки эффектов;
- глаз с числом — сколько противников целится в эту карту.

`battle.js` — прототип ядра: целые числа, генератор с сидом, числа баланса в `RULES`, `LIB`, `PAS`, `FOES`, `FLOORS`. Это ориентир для ядра на C#, а не его код.

Проверить баланс без браузера: `node -e "require('./battle.js')"` загружает ядро в `globalThis.EnBattle`. Забег считает `EnBattle.simRun(heroes, weekSeed, siegeHp)`.
