## Правила

Решения автора 27.09.2026:
- у героя без доблести одна активная способность, каждая доблесть открывает новую, последняя доблесть — ульту. Так и у героя с одной доблестью;
- доблесть даёт ещё и +30 % к базовым характеристикам (§3);
- **что открывают доблести между первой активной и ультой — свободно.** Набор собирается под героя: полноценный герой, свои синергии или синергии с другим героем. Можно и несколько ульт;
- виды по ролям: маг и физ ДД наносят урон, их пассивки усиливают урон; лекарь лечит, баффает и ставит щиты; танк живёт дольше и стягивает агро; контроль — дебаффы и контроль; фарм-герой усиливает добычу отряда;
- школа — стихия героя. Фарм-герои и герои без стихии берут набор «Без школы», фарм-герои — ещё и набор фарма;
- чем реже герой, тем чаще срабатывают его способности;
- провокации нет: танк держит врагов множителем угрозы (§5.3);
- враги Мастерской берут записи библиотеки по классу и стихии, как герои. Уникальные способности серьёзных противников автор обдумает позже, пока — общая библиотека.

**Как собраны наборы.** Вручную — «Хранители Песочных Часов»: это образец. Остальные 105 героев пока собраны автоматом по ролям классов; их пересоберём вручную сет за сетом.

## Шанс по редкости

Множитель редкости умножает шанс каждой способности героя. Базовые шансы библиотеки: активная — 20 %, контроль — 15 %, ульта — 10 %. Сумма шансов карты — не больше 60 %, больше — сжимается пропорционально (§5.1).

| Редкость | Шанс × | Активная | Контроль | Ульта | Две активные и ульта | Три активные и ульта | Если потолок растёт: потолок | две активные и ульта | три активные и ульта |
|---|---|---|---|---|---|---|---|---|---|
| обычная | 1,00 | 20 % | 15 % | 10 % | 50 % | 60 % — потолок | 60 % | 50 % | 60 % |
| редкая | 1,05 | 21 % | 15,75 % | 10,5 % | 52,5 % | 60 % — потолок | 63 % | 52,5 % | 63 % |
| уникальная | 1,10 | 22 % | 16,5 % | 11 % | 55 % | 60 % — потолок | 66 % | 55 % | 66 % |
| эпическая | 1,15 | 23 % | 17,25 % | 11,5 % | 57,5 % | 60 % — потолок | 69 % | 57,5 % | 69 % |
| древняя | 1,20 | 24 % | 18 % | 12 % | 60 % | 60 % — потолок | 72 % | 60 % | 72 % |
| первородная | 1,25 | 25 % | 18,75 % | 12,5 % | 60 % — потолок | 60 % — потолок | 75 % | 62,5 % | 75 % |
| вневременная | 1,30 | 26 % | 19,5 % | 13 % | 60 % — потолок | 60 % — потолок | 78 % | 65 % | 78 % |

**Потолок съедает бонус редкости.** Три активные и ульта дают 70 % ещё у обычного героя, и потолок 60 % сжимает их одинаково у всех редкостей. Две активные и ульта упираются в потолок с древней редкости. Предложение: потолок тоже растёт с редкостью — 60 % × множитель, до 78 % у вневременного. Тогда редкий герой чаще применяет способности при любом наборе.

## Как собирает автомат

Пока наборы не собраны вручную, автомат открывает доблести в таком порядке:

| Максимум доблести | Доблесть 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 1 | активная | ульта | | | | |
| 2 | активная | активная | ульта | | | |
| 3 | активная | активная | пассивка | ульта | | |
| 4 | активная | активная | пассивка | активная | ульта | |
| 5 | активная | активная | пассивка | активная | реакция | ульта |

Фарм-герою пассивка добычи открывается раньше второй активной. Виды — по ролям классов, ступени идут по кругу, чтобы наборы героев одного класса и стихии не совпадали:

| Класс | Доблесть 0 | Дальше по кругу | Ульта |
|---|---|---|---|
| танк | урон | дебафф, контроль, щит | щит, контроль, дебафф |
| лекарь | лечение | лечение по времени, щит, бафф | лечение, лечение по времени, щит |
| дебаффер | контроль | дебафф, урон по времени, контроль | контроль, дебафф, урон по времени |
| маг ДД | урон | урон по времени, дебафф, урон | урон, урон по времени, дебафф |
| физ ДД силы | урон | дебафф, урон, контроль | урон, дебафф, контроль |
| физ ДД ловкости | урон | урон по времени, урон, дебафф | урон, урон по времени, дебафф |
| фармящий | фарм | приём «Без школы», фарм | фарм |

Сборный герой с двумя классами открывает вторую активную из работы второго класса. Пассивка и реакция подбираются под роль. Двух одинаковых наборов нет.
