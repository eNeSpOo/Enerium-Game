«Древо рецептов» — вкладка презентации в прототипе `design/ui/`, рядом с «Картой экранов» и «UI-китом». Это инструмент команды и конструктора, а не экран игрока (ADR-0008): весь набор со спойлерами цикла VI, поиск по названию и фильтр по ресурсу. Градация всех ресурсов по циклам и ярусам — раздел «Ресурсы Этериоса» в UI-ките: иконки-заглушки, подсказка с загадкой и источником, переход в древо.

Черновики собраны скриптами из `tools/content-gen/`. Правьте исходники там, иначе следующая сборка затрёт правку.

Спойлеры: всё с пометкой «для команды», цикл VI рецептов и раздел 38 GDD в тексты для игрока не переносить.
