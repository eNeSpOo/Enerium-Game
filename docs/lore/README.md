# Лор

| Файл | Что |
|---|---|
| `Энериум — единый свод лора.docx` | Полный авторский свод. **Содержит спойлеры** — только для команды |
| `свод-лора-текст.txt` | Тот же свод текстом, для поиска |
| `Мастерская форм — записи сказителя.pdf` | Первый биом глазами старого сказителя: образцы, прислуга, босс, страж — с иллюстрациями |
| `мастерская-форм-текст.md` | Текст этого PDF по страницам |
| `дайджест.md` | Выжимка для интерфейса и текстов: что игрок знает в начале, словарь, мотивы и палитра, голос, запретные спойлеры |

Правила:
- В тексты для игрока идёт только то, что игрок уже может знать. Что знать рано — в дайджесте, раздел «Нельзя показывать раннему игроку».
- Имена и способности врагов раскрывает первая победа над ними (GDD §7).

## Уточнения автора

Уточнения автора важнее текста свода, если они расходятся.

- **Карст** (28.09.2026, ADR-0022). Пустой карст был всегда. Печать дала энтриархам способность его заряжать, после этого и пришёл золотой век.
- **Намёки на Странника** (28.09.2026, ADR-0022). Ролики автора расставляют чеховские ружья сюжета. Текстом намёки идут с цикла III, до этого игрок погружается в игру.
- **Донатные герои — Безликие** (ADR-0021, ADR-0022). Без лица и без памяти. На последней доблести герой вспоминает миг перед смертью и свою личность. Последние сеты — легендарные души тех, кого Этрион забрал в Башню вневремени. Лица у Безликих стёрлись; имя и облик — одежда, силуэт, приметы — видны сразу (ADR-0023).
- **Отмеченные** (28.09.2026, ADR-0022). Их миг перед смертью — встреча со взором своего бога. Этот миг их сломал, после него их забрал Этрион.
- **Звери** (28.09.2026, ADR-0022). В картотеке звери — народ: разумные, с душой. Простых животных там нет.
- **Эндалор** (28.09.2026, ADR-0023). Всех, кто умер в Эндалоре, сжигают по правилу метки, дворфов тоже.
- **Забытые** (28.09.2026, ADR-0023). Они есть только в памяти, которую показывает Этрион: своя неделя в Эхо и скрытые призывы. Призванный враг бывает любой расы — это память о тех, кого уже нет. Тип врага шестой ступени зовётся «Пробуждённый» (ADR-0054): Многоликий и пробуждённые из призыва; «Забытые» — только раса. По расе Многоликий — Забытый.
- **Эльфы в школе Времени** (28.09.2026, ADR-0023). Редкость: на всю игру не больше двух.
