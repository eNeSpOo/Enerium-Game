# Состояние

Обновляется в конце каждой сессии. Здесь то, что происходит сейчас; история — в `docs/progress/`.

**26.09.2026 — геймдизайн всей игры.** Репозиторий собран и отправлен на GitHub. Приняты решения автора:
- проектируем всю игру, а не MVP; таблицы автора — исходные постулаты (ADR-0003);
- класс задаёт роль, школа — стиль; «безэлементные» — приёмы классов (ADR-0004);
- бой до пяти на пять, враги — карты, без попыток и энергии, босс — осадой (ADR-0005);
- ступени орденов по §30, герой — в одном ордене (ADR-0006);
- биом на истощение; каждая карта на своей скорости, у каждого действия свой эффект; ускорения нет, свёрнутых забегов несколько; старт без героев (ADR-0007).

Черновики контента в `docs/content/`, по просьбе автора:
- герои: 22 сета, 110 героев, 330 глав по доблести, 8 недостающих сетов — названия и темы;
- ресурсы, рецепты и дроп на 6 циклов; окно «Древо рецептов» в прототипе;
- разбор референсов: навыки, 10 раундов, баф карт, сложности этажей.

Кода игры нет. Есть тестовая сцена боя в прототипе интерфейса `design/ui/`:
- ядро `battle.js`;
- эффекты `fx.js`, каталог из 21 вида и легенда знаков на вкладке «UI-кит»;
- экран боя в `index.html`.

Решения автора по черновикам — ADR-0008. Дальше — два чата:
- графика через Gemini API в стиле автора, по лору: портреты, враги, иконки, талисманы, ресурсы;
- вариант боя «10 раундов» с шансом срабатывания способностей для сравнения; биомы без бесконечного фарма; древо рецептов как инструмент разработчика; герои в UI-ките; правки сетов по ADR-0008.

От автора ждём:
- решения по разделам «Открыто» в черновиках `docs/content/`;
- ответы на три вопроса разбора референсов: сложности биома, бафы в школах, предел по времени вместо раундов;
- решение о бюджете доблести орденов;
- таблицу героев: кто в каком ордене, главы, личные максимумы;
- сколько биомов можно вести одновременно;
- отзыв о темпе, индикаторах и эффектах боя.
