# 2026-09-29 — правки автора: герои и отряды, неделя, контракты, ритуалы, клан, Арена, Событие, снаряжение, достижения

Автор посмотрел ночную партию и дал два десятка правок: «больше воздуха в каждом окне», «больше пафоса во врагах и героях», «все вопросы — реши сам». Решения — ADR-0029. Работали две волны подагентов, каждого проверил скриптами и в браузере.

- **Арт — $4,22.**
  - Способ глубокого промта — `art/style/style.md`.
  - Биом 3 нарисован заново, ещё пятеро героев.
  - Осколки зеркала для Памяти.
  - Рисованные сундуки: корпус и крышка слоями, замок, текстуры света.
- **Первая волна:**
  - «Герои» — одна плитка героя с кристаллом, доблестью и пределом;
  - отряды — библиотека с именами и один лист выбора на все режимы (`SQ`);
  - «Неделя» — прошлая, эта, следующая, реестр `WEEK_MODES`;
  - цена атаки в выборе цели Эхо;
  - контракты;
  - крафт — удача и неудача, лавка;
  - Память — сборка из осколков;
  - новая режиссура сундука.
- **Вторая волна:** ритуалы, клан, Арена и Лига, Событие, «Запасы» из семи вкладок и снаряжение, достижения, боковая панель.
- **Проход по стыкам:**
  - задание клана только в клане;
  - очки События в контрактах;
  - одна формула боевой мощи;
  - одно правило открытия Лиги;
  - старые заглушки убраны.
- **Проверки:** 25 скриптов, все проходят. Новые — `check_heroes`, `check_squads`, `check_week`, `check_contracts`, `check_shop`, `check_rituals`, `check_clan`, `check_arena`, `check_event`, `check_equipment`, `check_shell`.
- **Подводные камни:**
  - `check_chest_open` брал список выгруженного арта из самого экрана — сценарий «без арта» падал после выгрузки;
  - при удалении стилей лавки ушло правило, которое случайно раздувало счётчик эффектов на карте бойца;
  - браузер держит старые `screens/*.js` в кэше — для проверки обновлять кэш запросом с `cache: 'reload'`;
  - сборщики зависят друг от друга, порядок — в `tools/content-gen/README.md`.
