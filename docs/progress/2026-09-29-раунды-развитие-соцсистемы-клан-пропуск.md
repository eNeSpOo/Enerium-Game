# 2026-09-29, вечер — раунды по врагу, развитие героя, соцсистемы, Летопись, древо клана, пропуск, состав героев

Третий и четвёртый круги правок автора за день. Решения — ADR-0030.

- **Правила боя автора:**
  - раунды по типу врага — рядовые 5, элита 10, босс 20, рунный 25, Убер 50, крафтовый 75, клановый босс 100, Арена и Лига 25;
  - осада — здоровье на входе становится максимумом;
  - боссы Эхо и крафтовые живут час.

  Доблесть ×1,3 теперь в ядре. Пересчитано всё по порядку сборки.
- **Герой:**
  - развитие — один шаг на виду, превью доблести, анимации предела и доблести;
  - окно снаряжения с перетаскиванием;
  - рунные пределы — пять камней столбами по бокам портрета.
- **«Ремесло»:**
  - ползунок и лупа в Мастерской, сетка «Запасов» 6 × 5;
  - перековка — отдельная вкладка, игрок сам отмечает предметы.
- **«Призыв»:**
  - «За Энериум» — витрина-алтарь сета;
  - «За души» — сцена зеркала душ, лавка праха отдельным окном;
  - осколок героя — стекло, в котором лицо видно всегда;
  - героев Эхо нельзя собрать прахом.
- **Общение:** профиль по портрету, друзья, почта, чат RU/EN, облик Странника — рамки, частицы, портрет своего пола.
- **Летопись в «Страннике»** — 23 главы, пять городов без Эуклида, пятеро Энтериалов.
- **Клан:** древо на 100 уровней с вилками кланового босса. Клановый босс и элиты — семь стихий, лор и арт.
- **Арена и Лига** — пропуск, статистика, автообновление, сдвиг защиты 35. **Пропуск** — сезон 4 недели. **Дар дня** — лист из 30.
- **Состав героев по решению автора** — золото только обычная и редкая, потолок рулетки по циклу. Дух обучения — 2 000: вернулась петля трёх забегов.
- **Подводные камни:**
  - ×1,7 на маленьких группах даёт ложную тревогу — проверка Арены теперь учитывает шум;
  - после правки ядра порядок сборки обязателен: перемеры `--sim`, затем по шагам README;
  - сервер прототипа иногда останавливается — перезапускать через preview.
