# 2026-09-26 — истощение и эффекты боя

- Автор посмотрел тестовую сцену и уточнил решения. Записаны в ADR-0007:
  - действия идут по одному, у каждого свой эффект;
  - биом на истощение, сид — сам биом;
  - ускорения нет, свернуть можно, забегов несколько;
  - старт без героев.
- Ядро `design/ui/battle.js`:
  - у каждого действия длительность на экране (`RULES.act`);
  - здоровье и павшие переходят между этажами;
  - демо-баланс пересчитан: полный отряд упирается в 25-й этаж, без лекаря — в 16-й, без танка — в 21-й.
- Новый `design/ui/fx.js`: 19 видов эффектов, каталог с предпросмотром на вкладке «UI-кит».
- Экран боя: очередь действий с эффектами, линии целей, карточка бойца, чипы свёрнутых забегов в верхней строке, график здоровья в итоге. Скорость ×1–×8 — только в боковой панели для проверки.
- Подводный камень: снаряды летят через requestAnimationFrame, а скрытая вкладка его придерживает. Попадание теперь гарантирует таймер, и срабатывает оно ровно один раз.
- Подводный камень: демо-прыжок к боссу не должен трогать осаду — отвязан.
- Осталось: проектный документ боя; библиотека способностей по ADR-0004; таблица героев; бюджет доблести; сколько биомов вести одновременно.
