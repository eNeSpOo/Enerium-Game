# 2026-09-28 — перенос UI-кита в экраны прототипа, главы героев Эхо

- Автор принял девять цивилизаций Эхо и три новых источника лутбоксов. Долю героев за золото, 67,8 %, оставили. Записано в ADR-0023 и ADR-0024.
- Главы 45 героев Эхо написаны: у всех 360 героев есть главы, всего их 631.
- **Перенос в прототип.** Работали параллельно. У экранов теперь общий договор `design/ui/screens/model.js`: запасы `S.bag`, API `BAG`, `CRAFT_SEGS`, `ACTIVATE`. Каждый экран лежит в своём файле `screens/*.js`, `index.html` только подключает их.
  - «Мастерская»: стол на настоящих рецептах, подсказки §12, книга, автодокрафт.
  - «Запасы»: вкладки §14.3, сундуки §14.4, «Дары путешествия».
  - «Эхо»: цивилизация недели, лестница, крафтовый босс и руина из запасов.
  - Старый инвентарь `S.items` убран, у игрока одни запасы.
- **Мои правки при проверке:**
  - карточка в «Запасах» до активации называла руину или босса — это против §12.5;
  - планки Эхо выдавались дважды — в листе Эхо и в «Дарах»; теперь только в «Дарах»;
  - в демо 12 рун предела I, чтобы предел можно было взять.
- **Проверка.** Пять проверок в Node: `check_craft`, `check_bag`, `check_echo`, `check_all`, `lootboxes/check_ui`. В браузере прошёл автодокрафт, открытие сундука, призыв босса, активацию руины и получение в «Дарах». Все 15 экранов рисуются без ошибок.
- **Открыто.** Заглушки и толкования — в `design/ui/screens/README.md`, на утверждение автора.
- **Подводный камень.** `index.html` правит один подагент за раз. Параллельная работа — только через отдельные файлы `screens/*.js`.
