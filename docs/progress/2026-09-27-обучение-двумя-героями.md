# 2026-09-27 — обучающий биом под двоих героев, страж из трёх карт

- Решения автора, записаны в ADR-0018:
  - биом 1 закрывают двое героев — столько их набирается за первый час;
  - рунный страж цикла I — Мастер и две элиты, по силам двоим;
  - во втором биоме — ещё трое героев до первой полной пачки: физ ДД, маг ДД, танк, лекарь, дебаффер;
  - после рунного босса второго биома — слово Этриона «Виал — это только начало…» и ролик автора.
- Прототип `design/ui/battle.js`:
  - на этаже не больше двух врагов;
  - здоровье врагов — 50 % (`foeHpPct`), босса — 400 %, Мастера — 50 % (`guardHpPct`), свита стража — Подмастерье и Мех.
- `index.html`: тексты стража берут число карт из данных.
- Прогон: пара танка и физ ДД без доблести берёт биом с нуля за 7 минут забегов, стража — с 42-го уровня. Другие пары с бойцом урона — за 9–18 минут, пары без бойца урона до босса не доходят. Первый этаж один герой берёт с 1-го уровня.
- Калькулятор: Т15 считает пару героев (`TUTOR_IDS`) и уровень, с которого пара берёт стража (`SIM_GUARD`).
- Обновлены: черновик экономики, GDD §5.7, §8.1, §31, README прототипа.
- Подводный камень: у Мастера 50 % здоровья, он хрупче своей свиты. При 100 % пару с танком губит его ульта-паралич.
- Слово Этриона звучит в конце цикла I, а второго биома в прототипе нет — показать его пока негде.
- Осталось: максимумы героев за золото в черновиках (ADR-0019); интерфейс трёх способов получить героя — следующая задача, план ждёт автора.
