# ADR-0009 — Арт через Gemini API: Nano Banana 2 и стиль шести референсов

- **Статус:** принято
- **Дата:** 2026-09-26

## Контекст

В ROADMAP было открыто решение «API для генерации арта». 26.09 сделаны шесть референсов, каждый на трёх моделях Gemini:
- ресурс;
- арена сверху;
- портрет героя;
- иконка доблести;
- бафф;
- способность.

Сравнение и промты — в `art/generated/gallery.html`, цены — в `tools/art-gen/README.md`.

Старый арт, нарисованный GPT, автору не подходит. Это награды, каменные панели, орнаментальная рамка и картуш.

## Решение

1. **Основная модель — Nano Banana 2** (`gemini-3.1-flash-image`): размер 1K, для арен 2K. По качеству она почти как Pro, а стоит вдвое дешевле.
2. **Nano Banana Pro** (`gemini-3-pro-image`) — точечно: для сложных сцен и там, где Nano Banana 2 не справилась.
3. **Nano Banana 2 Lite не берём** — выглядит заметно хуже.
4. Большие партии генерируем пакетным режимом (Batch API): он вдвое дешевле.
5. **Шесть референсов — основа стиля.** Арт GPT из репозитория убирается.
6. Массовая генерация начнётся, когда автор выберет основу систем — бой и биомы. До этого рисовать рано. Дальше идём постепенно: партии, одобрение автора, следующая партия.

## Следствия

- `tools/art-gen/`: модель по умолчанию — `nb2`, Pro включается флагом `--models pro`.
- Прозрачность получаем только так: ровный ключ, вырезание скриптом, проверка альфы числами. Шахматка вместо альфы — брак.
- Объём по прикидке — около 650 картинок, с переделками около 1 300 генераций. Это около $100 при смешанном выборе моделей и вдвое меньше пакетом.
- Ключ API лежит в `.env` и в репозиторий не попадает.
- В ROADMAP решение «API для генерации арта» закрыто.
