# ADR-0019 — Источники героев и их максимум доблести

- **Статус:** действует частично; собрано. Слова автора 27.09.2026.
  - строка «рулетка — максимум доблести 2–3» заменена ADR-0030, п. 5а: потолок рулетки растёт с циклом — II — 2, III — 3, IV–VI — 3–4; за золото — только обычные и редкие герои;
  - героев за Энериум уточнил ADR-0021: донатный сет из пяти героев цикла, с цикла II;
  - героев из рецептов уточнил ADR-0032 («Стадии знакомства с героем»): рецепт кладёт в запасы осколки героя, дальше — пробуждение за души;
  - расхождение с черновиками героев из «Следствий» решено пересборкой состава (ADR-0022, ADR-0023).
- **Дата:** 2026-09-27
- **Уточняет:** ADR-0016; §3.4 и §10 GDD, черновики героев `docs/content/герои/`.

## Контекст

По §10 у каждого героя свой личный максимум доблести, а таблицу «герой — цикл — максимум» автор контента даст позже. Обсуждая обучение цикла I (ADR-0018), автор связал максимум доблести со способом получения героя.

## Решение

Слова автора: «Герои за золото — там герои находятся, у которых может быть совершена только 1 доблесть. В рулетке (возрождение души) уже герои с 2–3 максимум. В Эхо награда среди всех игроков на сервере будет за места — сундуки с осколками героев: на втором цикле герой с первой доблестью, на 3 цикле со 2 доблестью и т. д., имеется в виду МАКСИМУМ доблестей. И в крафте так же будут спрятаны герои всех доблестей от 1 до 5. Все герои, которых получает игрок, приходят ему всегда с 0 уровнем и 0 доблестью, как и 0 рунным пределом».

1. **Максимум доблести задаёт источник героя:**

   | Источник | Максимум доблести |
   |---|---|
   | Найм за золото | 1 |
   | Рулетка — возрождение душ (§15) | 2–3 |
   | Эхо: сундуки с осколками за места среди всех игроков сервера | номер цикла − 1: цикл II — 1, цикл III — 2 … цикл VI — 5 |
   | Крафт: скрытые рецепты, а ещё лутбоксы со скрытыми рецептами в добыче с врагов | от 1 до 5 |

2. **Любой полученный герой приходит на 0-м уровне, с 0 доблестью и 0 рунных пределов.** Доблесть — только рунами доблести.
3. **Три способа получить героя:** купить за золото, купить за Энериум, активировать за души героя, собранного из осколков. Интерфейс всех трёх — задача прототипа, её предстоит продумать.

## Следствия

- По ADR-0016 последняя доблесть героя открывает ульту. У героя за золото доблесть одна: без неё он бьёт одной активной способностью, с ней — получает ульту.
- **Черновики героев расходятся с решением.** В `герои.csv` у 56 героев с получением «золото» максимум 1 только у пяти, у остальных 51 — от 2 до 5. Нужно либо снизить им максимум до 1 — тогда у каждого останется одна глава из 1–5, — либо перевести их в рулетку, крафт или Эхо. Решает автор; главы героев по доблести (§10) зависят от выбора.
- §3.4 GDD («70 % — за золото») при максимуме 1 означает, что большинство героев игры — с одной доблестью. Долю источников стоит сверить с этим решением.
- Калькулятор экономики считает доблесть по-прежнему: отряд прототипа идёт с доблестью 2 / 1 / 2 / 1 / 3, в обучающем биоме — без доблести.
