# ADR-0024 — Эхо: древние цивилизации и расовая неприязнь героев Эхо

- **Статус:** действует целиком; собрано. Слова автора 28.09.2026; п. 4 — какая неприязнь — решён по его поручению. Цивилизации автор принял 28.09.2026.
- **Дата:** 2026-09-28
- **Уточняет:** ADR-0023 (второй круг, п. 3); §3.4, §5, §17 и §38 GDD; черновик `docs/content/герои/состав-героев.md`.

## Контекст

Подагент состава свёл героев Эхо в отряды по девяти нашествиям. Шесть нашествий он придумал из истории этеров, три взял из свода. Автор отклонил подход: «Эти нашествия обесценивают условное прошлое Этериоса».

## Решение

1. **Эхо — отражение древних цивилизаций,** по одной на расу недели. Слова автора: «Древние цивилизации, они на то и древние, что они жили на Этериосе задолго до первых Этеров».
   - Тематика частично взята из нашего мира. Автор приводит для примера звёзды, Египет и майя. Цивилизация интересно сочетается с логикой Этериоса или хотя бы частично её использует.
   - Враги недели — нашествие этой цивилизации, в её тематике и её стиле.
   - Этрион нашёл воспоминания о ней и через них даёт игроку силу — сильных героев для спуска.
   - Все девять недель, в том числе три нашествия из свода, строятся по этому правилу.
2. **Только для команды.** Этеров создали пятеро. Мать до них сама создавала целые народы, и те потом пали. Это спойлер §38 и раздела дайджеста «Нельзя показывать раннему игроку». Игроку — только «древние цивилизации, жившие задолго до этеров». Что Этрион сам пытается их увидеть, игроку тоже не говорим.
3. **Пятеро героев Эхо недели** — отряд, который отбил нашествие этой цивилизации (ADR-0023, второй круг). Игрок собирает его по герою за цикл, со II по VI.
4. **Расовая неприязнь — особенность героя Эхо, а не способность.** Слова автора: «как у врагов по типу есть иммунитет к контролю, так и у этих героев есть расовая неприязнь по типу расы». Решено по поручению автора:
   - неприязнь направлена на расу своей недели — отряд отбил её нашествие;
   - эффект — +20 % урона по врагам этой расы, у всех пятерых одинаковый. Число — демонстрация, хранится в данных;
   - действует везде, где встречаются враги этой расы: в спуске, в Эхо, у рунных боссов.

## Следствия

- **Состав героев.** Девять древних цивилизаций. У каждой — тематика, стиль врагов, нашествие и отряд из пяти. 45 героев Эхо переписываются под них; в CSV появляется столбец «неприязнь».
- **GDD:** §3.4, §5 (особенности по рангу и расе), §17.
- **Ядро боя.** Неприязнь — поправка в формуле урона, как иммунитет по рангу. Врагам нужна раса. Делаем вместе с врагами Эхо.
- **Главы героев Эхо** пишутся после того, как автор примет цивилизации.

## Автор принял цивилизации — 28.09.2026

Девять цивилизаций из `состав-героев.md`, раздел «Отряды Эхо», приняты. Главы 45 героев Эхо пишутся в файлы глав своих циклов.
