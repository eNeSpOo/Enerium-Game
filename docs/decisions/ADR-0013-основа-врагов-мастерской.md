# ADR-0013 — Основа врагов Мастерской: выбор автора, Долгорукий — дебаффер

- **Статус:** принято. Заменяет состав рядовых из ADR-0012, п. 1–2.
- **Дата:** 2026-09-27

## Контекст

Портреты врагов Мастерской делались по одному, и много генераций ушло впустую. Автор выбрал арт всех врагов Мастерской из уже сделанного и назвал классы рядовых. Заново нарисован только Упор.

## Решение

1. Рядовые — по одному на каждый класс врагов из §3 GDD:

| Класс | Враг | Арт в `art/generated/enemies/` |
|---|---|---|
| физ ДД силы | Безликий образец | `foe-faceless__nb2.jpg` |
| физ ДД ловкости | Однорукий образец | `ws-onearm__nb2.jpg` |
| маг ДД, интеллект | Пустотелый образец | `wp-hollow__nb2.jpg` |
| танк, выносливость | Безголовый образец | `ws-headless__nb2.jpg` |
| лекарь, интеллект | Сырой образец | `ws-raw__nb2-mirror.jpg` — отражён по просьбе автора |
| дебаффер: интеллект, контроль | Долгорукий образец | `wp-longarm__nb2.jpg` |

2. Элиты, босс и рунный страж:

| Роль | Враг | Арт в `art/generated/enemies/` |
|---|---|---|
| элита, физ ДД силы | Подмастерье | `ws-apprentice__nb2.jpg` |
| элита, физ ДД ловкости | Резчик | `ws-carver__nb2.jpg` |
| элита, танк | Упор | `ws-prop__nb2-v4.jpg` — нарисован заново, лицо эльфийское правкой |
| элита, маг ДД, воздух | Мех | `ws-bellows__nb2-v2.jpg` |
| элита, лекарь | Штопарь | `ws-darner__nb2.jpg` |
| элита, дебаффер | Съёмщик | `ws-remover__nb2-v2.jpg` |
| босс биома | Первый набросок | `wp-first-sketch__nb2.jpg` |
| рунный страж | Мастер | `ws-master__nb2.jpg` |

3. Долгорукий возвращается дебаффером. «Контролёр» у автора — это дебаффер из §3 GDD. Пересохший образец в основу не входит.
4. Кадр у основы смешанный: портреты по пояс и фигуры в рост. Автор принял его как есть.
5. Врагов Мастерской без задачи автора больше не генерируем.

## Следствия

- В GDD §8.5 Долгорукий и Однорукий меняются ролями: Однорукий — физ ДД ловкости, Долгорукий — дебаффер.
- Упор нарисован по рецепту партии 2 — с тем же стилем, рамкой и референсами, что его соседи: `tools/art-gen/jobs/batch-02.json`, задание `ws-prop`. Лицо сделано эльфийским правкой готовой картинки: `tools/art-gen/jobs/enemy-portraits-edit.json`.
- Серия `tools/art-gen/jobs/enemy-portraits.json` остановлена. Правила промта из ADR-0012 остаются для врагов других биомов: без картинки-эталона в запросе, незаконченные эльфы Виала, враг в действии.
- Прототип — исполнено 27.09.2026 по плану, одобренному автором:
  - роли `o2` и `o6` в `design/ui/battle.js`;
  - арт основы — в карточки боя, полки биома, бестиарий и Эхо;
  - старые фигуры и залы GPT из PDF удалены.
