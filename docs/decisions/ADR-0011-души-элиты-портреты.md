# ADR-0011 — Души растут с биомом, этажи с несколькими элитами, враги — портретом

- **Статус:** действует частично; собрано. Решение автора 27.09.2026.
  - п. 5, «Забытый — одновременно ранг босса и раса», отменён ADR-0023, п. 4: ранг расу не задаёт;
  - тип «Забытый» уточнил ADR-0039: это высшая ступень по силе; раса и тип — разные оси;
  - п. 3, число активных биомов, уточнил ADR-0014, п. 3: забегов разом — номер цикла и ещё один от Памяти Странника;
  - п. 4, кадр врагов, уточнили ADR-0012 (эталон кадра — словами) и ADR-0013 (у основы Мастерской кадр смешанный).
- **Дата:** 2026-09-27
- **Заменяет:** ADR-0010, п. 4 — «каждая элита даёт одну душу».
- **Уточняет:** ADR-0009 (кадр врагов в арте), ADR-0010 (дроп).

## Контекст

- Расчёт экономики спросил: давать ли по душе с каждой из четырёх элит в свите рунного стража или одну награду за победу.
- Автор посмотрел врагов Мастерской, нарисованных через Gemini, и выбрал ракурс.
- Агент по врагам биомов 2–12 отметил две нестыковки: имя «Забытый» и застывших искателей в биомах 8–9.

## Решение

1. **Души — с каждой элиты, и растут с биомом.**
   - В биоме N каждая элита даёт N душ: в первом — одну, во втором — две и так далее.
   - Босс биома даёт больше: ориентир §9.1 — пять душ за номер биома.
   - Свита рунного стража — тоже элиты, с каждой падают души.
2. **Этажи с двумя и тремя элитами.** Колоды — готовые пресеты. Этажи одни и те же у всех игроков, чтобы в гонке на сервере не было случайности состава.
3. **Число активных биомов — рычаг фарма.** Артефакт на число активных биомов умножает добычу. Это задуманный рост.
4. **Враги — портретом.** Кадр — по пояс, как у портретов героев, чтобы враги перекликались с картами героев игрока. Это основа для всех врагов. Старые фигуры GPT не берутся даже как референс.
5. **«Забытый» — одновременно ранг босса и раса.** Забытые боссы — из расы Забытых.
6. **Застывшие искатели** могут встречаться на разных этажах биома.
