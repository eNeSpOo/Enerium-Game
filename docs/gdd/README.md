# Геймдизайн Энериума — указатель

Основа — сводная редакция от 26 сентября 2026 года, разрезанная по разделам; с тех пор разделы правятся по решениям автора (таблица ниже). Это **единственный** геймдизайн проекта: всё, что было до него, лежит в архиве и недействительно.

**Как читать.** Открывай только разделы, нужные задаче. Статусы внутри текста:
- «демонстрация» — разрешённая заглушка, не утверждённая механика;
- «предложение» и «открыто» — ждут решения автора;
- «ручка» — балансный параметр;
- «лор» — ожидаемое авторское наполнение.

Открытые вопросы и противоречия собраны в разделе 37.

Исходник основы — `Enerium_Game_Design_2026-09-26.docx` рядом; нарезка была механической, номера подразделов вида «1 1» записаны как «1.1». Прежние редакции разделов — в истории git.
