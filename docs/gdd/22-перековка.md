# 22 Перековка

Отдельная вкладка «Ремесла»; сток ненужного лута. **Десять предметов одной редкости → один случайный предмет редкостью выше.**

- **Три режима** — снаряжение, духовные талисманы и рабочие, каждый внутри своей категории (ADR-0030; рабочие — тоже десять, ADR-0031). На руны перековка не действует.
- **Что уйдёт, выбирает игрок:** он отмечает десять предметов одной редкости. Надетое и занятое отметить нельзя. Сервер проверяет список, итог — на сиде операции.
- **Результат никогда не той же или меньшей редкости** — иначе механикой не пользовались бы. Случайность в том, какой предмет, не в том, вырастет ли редкость.
- **Цена — золото,** растёт с циклом. Числа — в данных режимов: `docs/content/снаряжение.md`, `docs/content/талисманы.md`, `docs/content/ритуалы.md`.

Курс жёсткий: не лестница наверх, а утилизация с надеждой.
