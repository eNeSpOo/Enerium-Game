# 22 Перековка

Отдельное окно; сток ненужного лута. **Десять предметов одной редкости → один случайный предмет редкостью выше**; работает для снаряжения и духовных талисманов, на руны не действует. Результат никогда не той же или меньшей редкости — иначе механикой не пользовались бы; случайность в том, какой предмет, не в том, вырастет ли редкость. Курс жёсткий: не лестница наверх, а утилизация с надеждой. *(Открыто: цена операции; кросс-категорийность — предположительно внутри категории, иначе талисманы фармятся Ареной в обход КБ.)*
