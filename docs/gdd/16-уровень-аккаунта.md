# 16 Уровень аккаунта

**100 уровней.** `Награда = База × (1 + Уровень × 0,1)`; `Цена = 100 × уровень^1,5` (10-й ~17 000 накопительно, 100-й ~4 млн). **Опыт за вехи × цикл**; за рецепты опыта нет (иначе вики превращается в уровни).

| Действие | Опыт (× цикл) |
|---|---|
| Первое убийство нового существа | 50 |
| Первое закрытие биома | 500 |
| Первое убийство рунного босса цикла | 500 |
| Пробитие рунного предела | 150 |
| Доблесть герою | 300 |
| Первое убийство нового врага в Эхо | 100 |
| Покупка или активация героя | 200 |
| Переход на новый цикл | 2 000 |

## Уровни 1 10 сценарий

Не экономика, а чеклист. Цикл I — обучение на часы (ADR-0018): каждый уровень даёт валюту — ею покупают героев, — руны рунного предела и, во втором биоме, руну первой доблести. Сложность и фарм — с цикла II.

|---|---|---|
| 1 | Начало | первый герой, первый биом |
| 2 | Пройти 5 этажей | второй слот |
| 3 | Убить первую элиту | магазин |
| 4 | Закрыть первый биом | третий слот, артефакты |
| 5 | Первый рунный предел | руны предела — наградой уровня |
| 6 | Первый рунный босс | крафт |
| 7 | Первый рецепт | четвёртый слот |
| 8 | Открыть второй биом | второй отряд, руна первой доблести — для обучения |
| 9 | Второй рунный босс | пятый слот, фильтры инвентаря |
| 10 | Закрыть второй биом | **второй цикл, Эхо, кланы, рейтинг, квесты, возрождение душ, рынок** |

## 16.1 Окно уровня и источники опыта

Основной экран показывает текущий уровень, полученный опыт, порог следующего уровня и связанные открытия. Кнопка источников открывает компактное окно с иллюстрациями и конкретными значениями для текущего цикла. У каждой вехи видны условие первого получения и награда; длинный список не должен перекрывать действия и закрытие.

Источники опыта и сценарий первых десяти уровней разделены. Выполнение шага обучения «первый рецепт» может открыть сценарный этап, но не создаёт повторяемый источник опыта за рецепты. Начисление связано с подтверждённым достижением условия, а не с чтением диалога.

Таблица XP сохраняется как исходный рабочий баланс. Последовательность обучения выше требует увязки с новыми воротами рунных стражей и доступностью доблести; нерешённые зависимости перечислены в разделе 37.
