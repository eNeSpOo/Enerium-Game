# 4 Способности и ротация

**Набор способностей индивидуален.** Число активных навыков — 1, 2 или 3 по фактическому набору героя; также могут быть пассивные боевые и пассивные фарм-способности. Ультимейт есть только у тех героев, которым он назначен: даже достижение пятой доблести, если она доступна, само по себе не гарантирует ультимейт. Обязательного одинакового набора из шести способностей нет.

Способности открываются доблестью по заданному для героя порядку в пределах его личного потенциала. Ступени открытия определяются авторским набором героя. Ограничение ультимейта пятой доблестью и особыми героями из скрытых рецептов рассматривается в последней редакции исходного GDD; прежний раздел допускал иные ступени. До окончательного согласования таблицы героев ранний ультимейт не считается подтверждённым правилом. **Нет активного скилла — нет ультимейта.** Окончательные наборы и ступени их открытия автор контента задаст отдельно.

**Цена в атаках.** У каждой активной — цена в обычных атаках; способность применяется вместо атаки: одно применение стоит цена + 1 удар. Пассивные цен не имеют и слотов не занимают. Нормировка: цена в условных единицах, в атаки — `условная цена × скорость атаки`, минимум 1: темп по времени у всех одинаковый.

**Библиотека.** Пул на класс: 5 активных, 3 пассивных боевых, 3 пассивных фарм, 3 ультимейта = 14. Шесть классов — **84 способности на всех золотых героев** *(ручка: число выросло вместе с классом ловкости)*. Герой — индивидуальная выборка из пула класса; число комбинаций требуется пересчитать под разные наборы и личные пределы (прежний ориентир: 270 комбинаций на класс). Баланс переносится с героя на способность: правишь общую библиотеку, а не каждого героя отдельно; ручка каждой — цена в атаках. *(Окончательный пул 84 и особый фармящий класс — авторский контент и конструктор.)*

**Ротация** — порядок активных способностей; меняется перетаскиванием в карточке героя. Порядок не меняет длину цикла — решает, что успеет отработать в коротком бою. Ротация задаётся при подготовке. Управление записью детерминированного боя не меняет исход.
