# 27 Событие

Метарежим недели расы: не локация, а бухгалтерия недели. Очки — за активности по всему проекту: контракты, закрытие биомов, ритуалы, победы в Арене и Лиге, Эхо, лестница КБ *(таблица «активность → очки» — финальная сборка, открыто)*. Первая РП.

Три слоя наград: личные планки по накопленному, клановые планки, поверх — межсерверный рейтинг игроков и рейтинг кланов с призовыми местами. Главная награда — **лутбоксы рабочих** (инфраструктура: быстрее ритуалы → больше офлайн-дохода; ритуалы возвращают очки в Событие — круг замкнут). Логика раскладки: контракт — личная дисциплина, платит личным прогрессом (ключи); Событие — марафон всей недели, платит инфраструктурой (рабочие).
