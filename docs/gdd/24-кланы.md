# 24 Кланы

Клан обязателен: клановое древо и клановые планки безальтернативны. Экран поиска (список, сила, численность) открывается уровнем аккаунта.

## 24.1 Паспорт

Название, эмблема, описание, **тип** (Хард / Средний / Чил), принципы, направление, цели на день, неделю и месяц. Вместимость 25 → 35 (+1 за каждый 10-й уровень древа). **Роли** *(UX — открыто)*: ГМ сам называет роли, раздаёт обязанности по силе и активности, с капами по ролям.

## 24.2 Древо

**Сто уровней: четыре ветки по десять, затем круг повторяется** — Сила в бою (урон по типам, множители атак, щит, лечение) → Стихии (урон по элементам) → Добыча (золото, дух, души, ключи, ресурсы, осколки) → Время и выносливость (секунды за врагов, добавка к боссу, длительность контроля, сопротивления). Порядок не случаен: клан учится бить, потом бить правильно, потом собирать, потом выживать.

На каждом уровне ГМ выбирает **одну пассивку из 1–5 альтернатив** — кланы получают лицо; **сброс древа за Энериум** с новым распределением — эксперименты легальны. Каждый пятый уровень первого круга — +1 попытка КБ (4 за 40); в следующих кругах те же слоты — пул элит, скорость резервуара, длительность бонусов. Каждый десятый — +1 вместимость. На каждом пятом уровне веток — пассивки, влияющие на тактику убийства КБ *(состав — открыто)*.

**Законы:** клановые бонусы не действуют в PvP; пассивки только по каноническим спискам 7 элементов / 6 боевых классов / 10 рас.

## 24.3 Резервуар

Наполняется контрактами участников (половина очков каждого выполненного). Заполнился — очко навыков, ГМ распределяет. `Требование = База × Уровень^1,5`: первый уровень за пару дней, сотый — к концу второго года активного клана. Уровень клана = потраченные очки.

## 24.4 Награды

Вклад считается автоматически (контракты в резервуар, урон КБ, личные очки). **Половина клановой награды — сервером по вкладу, половина — на усмотрение ГМ**; лог распределения виден всем и не стирается при выходе: злоупотребление — публичный факт. Личный рейтинг и его награды от ГМ не зависят.
