# 6 Боевая мощь БМ

Витринное число: карточки врагов (Эхо, КБ), панель отряда, профиль. **Законы:** БМ не входит ни в одну игровую формулу; контекстные множители (элемент, расовые модификаторы, клановые бонусы) в БМ не входят — элемент показывается рядом отдельно: мощь — арифметика, элемент — головоломка игрока.

```
УВС = Урон × СкоростьАтаки × (1 + Крит × (КритУрон − 1)) × К_ротации
Смягчение = Защита / (K × Уровень + Защита)          — эталон своего уровня, кап 50%
ЭЗ = Здоровье / ((1 − СмягчениеСр) × (1 − Уклонение))
БМ героя = C × √(УВС × ЭЗ)
БМ отряда = Σ БМ героев
```

Геометрическое среднее наказывает перекос и растёт линейно с силой. C — косметическая константа *(ручка)*. Враги считаются той же формулой из своих статов. `К_ротации` — вклад способностей: ротации в бою нет (ADR-0010), имя множителя осталось прежним.

**Слои.** Каждый слой уточняет множители, не меняя формулу, интерфейс и сериализацию:
- слой 0 — только статы, К_ротации = 1;
- слой 1 — вклад способностей: средний множитель урона от способностей набора, лечение засчитывается как урон. Считается одинаково для героев и врагов: с чертами и сочетаниями герой сильнее своего числа, враг с чертой — тоже (ADR-0051);
- слой 2 — снаряжение и талисманы: статы входят автоматически, боевые пассивки — множителями;
- слой 3 — ролевые поправки: вклад лекаря в ЭЗ отряда.

**Слой 1 — как считается** (ADR-0051). `К_ротации` — во сколько раз средний ход карты ценнее обычной атаки. Ход — один бросок таблицы шансов (§5.1): способность с её шансом даёт свою цену, остаток — обычная атака.
- Урон, лечение и щит — коэффициент способности на число целей.
- Урон и лечение по времени — коэффициент на раунды, стаки и число целей.
- Контроль, дебафф и бафф урона не несут: их цена — за цель и раунд, числом из данных.
- Сочетание — сумма двух частей. Ход способностью не дешевле обычной атаки.
- Каждая пассивка и реакция набора — черта героя или врага — прибавляет к множителю свою долю.
- Карта без способностей — `К_ротации` = 1, то есть слой 0.

Числа — `RULES.bm` ядра: демонстрация.

**В прототипе** собраны слои 0, 1 и 2. Формула — одна функция ядра `EnBattle.bm` в `design/ui/battle.js`: её зовут экраны (`BM` в `design/ui/index.html`), бестиарий биомов, клан и лестница врагов (§7). Закон «БМ — витрина» сверяет `tools/content-gen/abilities/check_core.js`: исход боя от чисел мощи не зависит.
