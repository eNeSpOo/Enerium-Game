# 6 Боевая мощь БМ

Витринное число: карточки врагов (Эхо, КБ), панель отряда, профиль. **Законы:** БМ не входит ни в одну игровую формулу; контекстные множители (элемент, расовые модификаторы, клановые бонусы) в БМ не входят — элемент показывается рядом отдельно: мощь — арифметика, элемент — головоломка игрока.

```
УВС = Урон × СкоростьАтаки × (1 + Крит × (КритУрон − 1)) × К_ротации
Смягчение = Защита / (K × Уровень + Защита)          — эталон своего уровня, кап 50%
ЭЗ = Здоровье / ((1 − СмягчениеСр) × (1 − Уклонение))
БМ героя = C × √(УВС × ЭЗ)
БМ отряда = Σ БМ героев
```

Геометрическое среднее наказывает перекос и растёт линейно с силой. C — косметическая константа *(ручка)*. Враги считаются той же формулой из своих статов.

**Слои внедрения:** слой 0 (MVP) — К_ротации = 1, только статы; слой 1 — К_ротации из цикла боя (средний множитель урона по ротации, лечение засчитывается как урон); слой 2 — снаряжение и талисманы (статы входят автоматически, боевые пассивки — множителями); слой 3 — ролевые поправки (вклад хилера в ЭЗ отряда). Каждый слой уточняет множители, не меняя формулу, интерфейс и сериализацию.
