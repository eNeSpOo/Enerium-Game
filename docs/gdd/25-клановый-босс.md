# 25 Клановый босс

Командная лестница без потолка; клан — единый организм: слабые кормят призыв, сильные пробивают верх. Пятая РП; награды — лутбоксы с талисманами. **Лестница и очки обнуляются каждую неделю расы**; босс недели относится к текущей расе; его боевой элемент задаётся отдельно таблицей контента.

## 25.1 Атаки

У каждого участника **5 атак в день** (растёт древом), **общий кошелёк** на элит и босса — кто тратит на призыв, кто бережёт для КБ, решает клан. На атаку — лимит времени внутри этажа *(ручка)*. UX: при первом входе обязательная установка атакующего отряда; дальше — пресеты (под элит, под КБ разных недель и их боевые элементы).

## 25.2 Круг

1. В окне клана по умолчанию призваны **3 элиты** (пул растёт древом: больший пул — выбор целей, меньше вынужденных атак в неудобный элемент). Призыв бесплатен и автоматичен.
2. **Элемент каждой элиты — чистый рандом из семи.** Осознанно: рандом — фактор, разнящий кланы; клан без контр-отряда против выпавшего элемента платит потерянными атаками. Ответ — не правило, а прогрессия: качать всех героев, строить семь контр-отрядов, покупать пул элит.
3. До убийства видны только мощь, здоровье, элемент, тип (правило бестиария).
4. **Сопротивлений у элит нет** — испытание в подборе отрядов.
5. Три килла элит → **автопризыв Кланового босса** недели расы; все висящие элиты **сгорают**, КБ — единственная цель; контроль на него не действует, только дебафы.
6. Убили КБ → очки → новый круг: статы элит и КБ × X *(главная ручка режима)*. Лестница бесконечна; потолок каждого клана — его сила.

**Действует сейчас (ADR-0030, ADR-0031):** элита — этаж из пяти врагов её стихии: Голос (маг ДД) и свита — Щит, Лекарь и двое Пут; клановый босс — Хозяин стихии (маг ДД) с Клинком, Стрелой, Щитом и Лекарём. Бой элиты — 10 раундов, босса — 100. «Атаковать всеми» тратит все оставшиеся атаки одной операцией с общим итогом. Лор, имена и совет старика — `docs/content/клан.md`, «Сонмы стихий».

## 25.3 Очки

```
Очки участника = Очки врага × (его урон / здоровье врага)
```

Урон копится в счёте врага; **выплата в момент его смерти** пропорционально вкладам; бонуса за добивание нет (снайпинг бессмыслен, вклад слабых оплачен честно). Не умер до конца недели — счёт сгорает: клан сам координируется добивать. Оверкилл — по снятому. Элиты платят меньше КБ; очки растут со ступенью.

**Планок нет** — только рейтинг всех игроков (личные очки) и рейтинг всех кланов (сумма). **Анти-прыгун:** вклад — клану, в котором игрок состоял в момент смерти врага; вступивший вносит в новый клан со следующей недели.

## 25.4 Раса недели и элемент цели

**Действует сейчас (ADR-0031):** Хозяин недели — по ротации девяти недель рас: Люди — Вода, Дворфы — Земля, Эльфы — Воздух, Звери — Огонь, Саганы — Свет, Аппараты — Огонь, Искажённые — Тьма, Нежить — Время, Забытые — Земля; Огонь и Земля не идут подряд. Стихии элит круга — случайно из семи, без повторов в круге. Все фигуры сонмов — раса Саганы.

Календарь кланового режима использует общую неделю расы. Ранее привязанный к названию недели элемент больше не выводится из неё автоматически. Правило случайного элемента элит из семи сохраняется как рабочая основа. Состав боссов по девяти расам и распределение их элементов ещё нужно задать авторской таблицей.
