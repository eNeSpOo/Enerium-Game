# 33 UX ключевых окон

## 33.1 Найм героя витрина до покупки

Видно всё: рамка; иконка редкости; личный потенциал доблести в звёздах и текущая / максимальная ступень; предусмотренные для этого героя аватары и главы *(лор)*; раса, имя, класс; кнопка покупки; вторичные статы — скорость атаки, шанс крита, крит. урон, уклонение, агро, физ/маг урон %, физ/маг защита %, здоровье, урон; **характеристики с СРХ, подсвеченными партиклами**; боевая мощь; цикл; описание; **все способности, доступные этому герою при его личном максимуме**, и рейтинговые пассивки в той же панели. Наличие ультимейта показывается по набору героя и не подразумевается по умолчанию. Герой неоткрытого цикла — панель-блок на просмотр скиллов до перехода на цикл.

## 33.2 Карточка купленного героя

По нажатию на аватар — расширенная карточка: уровень / рунный предел / доблесть «текущая / максимальная» / БМ — иконка + цифра; звёзды потенциала по правилу 10.2; пять статов с СРХ-партиклами и тултипами «что даёт стат»; здоровье баром; переключатель атакующих/защитных атрибутов; имя, роль, элемент, раса — иконками. **Прокачка уровней пачкой:** выбор «сколько за раз», хоть до предела, если хватает духа. Попапы предела и доблести: сколько нужно / сколько есть / что произойдёт; на личном максимуме повышение доблести недоступно и причина видна. Главы и аватары — по фактическому содержанию героя. Способности с тултипами (цифры и описание); **смена ротации перетаскиванием скиллов**. Отображается фактический набор из 1–3 активных навыков с их доступностью по доблести; индикатор ультимейта предусмотрен только для героя, у которого он есть. Недостижимые ступени и отсутствующие способности не изображаются как будущие награды. Слоты снаряжения (9) и талисманов (4): перетаскивание из инвентаря, полная информация предмета; на MVP — заглушки.

*(Референс-скрин 21.08: 6 слотов снаряжения и без ротации — устарел; полный UX-проход всех режимов с попапами — отдельный этап после закрытия механик.)*

## 33.3 Общие правила окон

Попапы закрываются крестиком и нажатием на чёрное затемнение вне окна. На устройствах с клавиатурой поддерживается Escape. Нажатие или жест внутри окна не считаются нажатием на фон. Закрытие подтверждения отменяет неподтверждённую операцию; оно не означает согласие на расход.

Вложенные сведения возвращают к прежнему экрану с сохранением вкладки, выбора и положения списка. Окно записи боя может быть закрыто сразу с переходом к подтверждённому итогу. Длинные списки прокручиваются внутри своей области, а нужные для работы заголовки, поиск и действия остаются на экране.

## 33.4 Требования к основным сценариям

| Сценарий | Видимая информация и действие |
|---|---|
| Мастерская | Подписанные зоны инвентаря и крафта, компактные ячейки, шесть мест рецепта |
| Книга рецептов | Плотный список, закреплённые поиск, фильтры и избранное |
| Дары путешествия | Две категории наград, сумма сундуков, просмотр состава и получение в инвентарь |
| Убежище | Перспектива NPC, доступ к разговорам, текущие занятия и следующий шаг |
| Диалог | Текст и ответы слева, крупный персонаж с именем справа |
| Бестиарий | Биом и подробности после первого убийства, удобное чтение навыков |
| Эхо | Сохранённая пятёрка, цена и цель атаки, немедленный переход к итогу |
| Память | Пять мест, тройка на выбор, эффект выделенной иконки, переброс и закрепление |
| Профиль | Активность аккаунта, сумма БМ пятёрки, доблесть и рунные пределы, клан и общение |
| Источники опыта | Значения текущего цикла, условия вех, отдельное объяснение обучения |

Для горизонтальных телефонов главные кнопки должны оставаться доступными при открытой информации и прокрутке. Размеры иконок подбираются по плотности и читаемости, без увеличения каждого предмета до отдельной большой карточки. Окончательная визуальная приёмка экранов остаётся отдельным этапом.
