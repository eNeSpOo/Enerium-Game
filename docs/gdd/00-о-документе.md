# Энериум Игровой документ

Сводная редакция 26 сентября 2026 года

Документ объединяет основную игровую систему Энериума и решения, принятые при работе над интерфейсом и прогрессией. Он предназначен для геймдизайна, авторского наполнения и разработки: правила обновлены внутри разделов, чтобы по ним можно было продолжать работу без восстановления переписки.

Последние прямые уточнения автора имеют приоритет над старой редакцией. Сохранённые числа исходного GDD являются стартовыми параметрами под прогоны, если рядом не указан другой статус. Принятые фиксированные цены — призыв противника Эхо за 1 душу, платный переброс Памяти за 50 Энериума и полный сброс за 100 Энериума.

**Как читать статусы.** «Демонстрация» означает разрешённую заглушку для проверки представления, а не утверждённую механику. «Предложение» и «открыто» требуют дальнейшего решения. Пометка «ручка» в сохранённых разделах означает настраиваемый балансный параметр; «лор» — ожидаемое авторское наполнение. Рабочие детали UIKit не становятся принятыми только потому, что реализованы в прототипе.

Раздел 37 собирает открытые вопросы и противоречия, раздел 38 содержит внутренние сюжетные сведения для команды, раздел 39 перечисляет источники. Новые пассивки из таблицы пока используются только для показа и не подключаются к реальным расчётам.
