# 32 Монетизация витрины

**Боевой пропуск:** два трека, сезон; прогресс купить нельзя — только очки за активность. **Косметика:** аватары, рамки, эффекты, шрифты; большая часть зарабатывается достижениями, уровнем, доблестями и топами — знак отличия, а не товар. **Запретный магазин:** разовые покупки Энериума с удвоением первой, подписки с ежедневной выдачей, наборы со скидками, лимитированные предложения.
