# 32 Монетизация витрины

**Боевой пропуск:** два трека, сезон; прогресс купить нельзя — только очки за активность. **Косметика:** аватары, рамки, эффекты, шрифты; большая часть зарабатывается достижениями, уровнем, доблестями и топами — знак отличия, а не товар. **Донатный сет цикла** (ADR-0021): пятеро героев за Энериум, с цикла II, любой из пяти, цена растёт от первого к пятому; сила — в пользе для аккаунта, а не в бою. **Запретный магазин:** разовые покупки Энериума с удвоением первой, подписки с ежедневной выдачей, наборы со скидками, лимитированные предложения.
