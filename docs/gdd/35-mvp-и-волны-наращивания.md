# 35 MVP и волны наращивания

## 35.1 Состав MVP

Биомы, враги, Хаб, Найм героев (с полной витриной), ротация, Рунные боссы, прокачка и покупка героев, элементы, классы, редкости, рунные пределы, доблесть, Эхо, **Артефакты**, Уровень аккаунта, Квесты (контракты), Крафт, рецепты, ресурсы, Инвентарь, Бестиарий, Странник (пассивки + профиль), магазин, рынок, возрождение душ.

**Заглушки в UX** (вшиты заранее, закрыты панелями): снаряжение (9 слотов), духовные талисманы (4 слота), ритуалы, кланы (клановая половина очков контрактов — в счётчик-заглушку), Арена и Лига, Событие-рейтинг, перековка, боевой пропуск. MVP рисует силуэт полной игры.

**14 героев-заглушек.** Прежний шаблон 3 активные / 1 пассивная боевая / 1 пассивная фарм / 1 ультимейт сохраняется как пример тестового наполнения, а не обязательный набор каждого героя. При окончательном наполнении каждому герою назначаются личный максимум доблести, 1–3 активных навыка по его набору, пассивные способности и наличие либо отсутствие ультимейта. Для героя с ультимейтом до его зарядки учитываются три применения активных навыков, в том числе повторные, а не обязательно три разных навыка. Распределение героев по циклам и их личные пределы автор контента задаст отдельно. Прежние примеры наборов циклов 1–2: Танк — Вызов / Каменная кожа / Удар щитом / Несгибаемость / Трофейщик / Бастион; Хилер — Живая вода / Родник / Оберег / Отклик / Собиратель трав / Возрождение; Контроль — Оковы / Безмолвие / Ослабление / Тень / Дознаватель / Паралич; Физ ДД — Быстрый выпад / Шквал / Пробитие / Точность / Охотник / Казнь; Маг ДД — Разряд / Прожигание / Разрыв покрова / Средоточие / Знаток / Испепеление.

## 35.2 Волны наращивания порядок предложение двигается

**Волна 1 — Ритуалы и Рабочие.** Офлайн-фарм; временный источник шардов до События — лутбоксы контрактов.
**Волна 2 — Кланы, Клановый босс, Талисманы.** Резервуар оживает, клановая половина очков перестаёт быть заглушкой; талисманы закрывают свои слоты.
**Волна 3 — Арена и Лига, Снаряжение, Перековка.** Снаряжение закрывает слоты; в формулы входит слой 2 БМ.
**Волна 4 — Событие и лутбоксы.** Финальная сшивка недели: таблица «активность → очки», все категории коробок, перестройка источников шардов на постоянные.
**Волна 5 — Обвязка.** Боевой пропуск, косметика, Запретный магазин, календарь, достижения, ордены, полное обучение, настройки и промокоды.

Формулы наслаиваются вместе с волнами: производные добавляются в существующие формулы до конечных, без перестройки ядра.

## 35.3 Граница текущего прототипа

В этой редакции зафиксированы новые правила и требования к экранам. Первоначальная разбивка MVP и волн выше сохранена как план, а не отчёт о готовности. Самостоятельный UIKit показывает также системы будущих волн. Его работа не переводит автоматически эти системы в реализованный состав игрового клиента. При планировании нужно отдельно оценить серверные операции, авторский контент и финальный баланс.
